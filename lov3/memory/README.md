# Project memory — public, curated, version-controlled

This folder is the Book of LOV3 **project continuity layer**, not a copy of ChatGPT's internal memory.

**Start every development session by reading** `project-memory.json`, `lov3/README.md`, and the current open pull requests. Compare new decisions with existing code before changing anything.

The public memory contains only project-level concepts, architecture, and status. Do **not** commit full chat transcripts, private legal/family/health records, contact information, secrets, keys, or unpublished confidential works here.

## Updating memory
1. Review new project discussions and proposed decisions.
2. Obtain approval before recording anything sensitive or personally identifying.
3. Add concise factual project decisions and an ISO date, preserving prior records.
4. Review the diff and commit through a pull request.
5. Verify statements about deployment and test status from actual evidence.
6. Avoid implying the file automatically feeds all AI sessions.

For a private complete archive, use encrypted user-controlled storage in a separate restricted system with export and deletion controls. Git history is not an appropriate deletion mechanism for secrets.
